# projmon 🔭🔔
projmon : Monitoring Multiple Projects | Cloud Monitoring, Alerting, Notifications, Policies, Metrics, Dashboards, Uptime Check |


## Objectives
- Create a Cloud Monitoring account that has two Google Cloud projects.
- Monitor across both projects from the single Cloud Monitoring account.


## Similar Skills Set
- AWS : CloudWatch Alarms
- Azure : Azure Monitor Alerts
- Alternative : Prometheus + Grafana, Zabbix
